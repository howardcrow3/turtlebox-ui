# Turtlebox UI

The shared UX framework for Turtlebox apps and for every High Turtle website: design tokens, component styles, and the layout rules for chat-first desktop apps. CeeVee is the first app to adopt it, and Golden is the second and is on it (see `docs/GOLDEN.md`).

Status: draft v0.2, first uploaded for review. The design is not final until Howard approves it.

## What is here

| Path | What |
| --- | --- |
| `tokens/tokens.json` | Source of truth for color (light and dark), type, radius, density, space and motion |
| `css/tokens.css` | Generated from `tokens.json` by `scripts/build-tokens.py`. Do not edit by hand |
| `css/tokens-light.css` | Generated. Light only, plus web spacing and sizes, for websites |
| `css/web.css`, `css/fonts.css`, `fonts/` | Web layer: the same system at website scale (see `docs/WEB.md`) |
| `dist/web-light.css` | Generated by `scripts/build-web.py`: fonts, light tokens and web layer in one file for sites |
| `css/base.css` | Inter-only base type, focus ring, reduced motion |
| `css/charts.css` | Chart chrome, tooltip, tables, stat tiles, time bar and dashboard cards |
| `js/tb-charts.js` | Dependency-free chart kit: columns, lines, bands, bars, sparklines, time window overview, table view |
| `css/shell.css` | Generated: app shell only, for apps whose screens already use short class names |
| `css/extensions.css` | Segmented control, field, notice, badge, empty state, progress, data table, section (see `docs/EXTENSIONS.md`) |
| `css/components.css` | Framework-neutral styles for buttons, toggle, select, input, chip, nav, rows, modal, chat composer, result list, approval card, data table, board and chat dock |
| `docs/CHARTS.md` | Chart types, the time model and the chart rules |
| `docs/GOLDEN.md` | How Golden consumes the framework, what it adopted and what is left |
| `docs/DESIGN.md` | Principles, layout patterns, density, lists, chat and forms, themes, references, adoption plan |
| `preview/ux-plan-v0.2.html` | The live review page with all mockups. Open it in a browser |
| `scripts/build-tokens.py` | Regenerates `css/tokens.css` |

## Use on a website

Copy `dist/web-light.css` and `dist/fonts/` next to each other and link the CSS. Websites are light only. See `docs/WEB.md`.

## Use in an app

```html
<link rel="stylesheet" href="css/tokens.css">
<link rel="stylesheet" href="css/base.css">
<link rel="stylesheet" href="css/components.css">
<link rel="stylesheet" href="css/extensions.css">  <!-- optional, v0.3 -->
<link rel="stylesheet" href="css/charts.css">   <!-- only for apps with charts -->
<script src="js/tb-charts.js"></script>        <!-- only for apps with charts -->
```

Inter is loaded by the app, self-hosted in desktop apps. Light and dark follow the system by default. Set `data-theme="light"` or `data-theme="dark"` on the root element to force one.

Regenerate tokens after editing `tokens/tokens.json`:

```
python3 scripts/build-tokens.py
```

## Not here yet

- Svelte components. CeeVee's UI is SvelteKit, so these come first, built on this CSS.
- Class name prefixes. The names in `components.css` are provisional.
- A license. Add one before other people use this.
- Icon set. The preview uses a small hand-drawn stroke set that still needs to be replaced with a licensed one.
